## 2. La regola che vale per qualsiasi nome: il cognome

- Chi gestisce da solo un'azienda «deve assumere come elemento essenziale
  della ditta il suo cognome, con o senza nomi». Non sono permesse aggiunte
  che fanno pensare a una società
  ([art. 945 CO](https://www.fedlex.admin.ch/eli/cc/27/317_321_377/it#art_945)).
- Il RC Ticino precisa che il cognome deve essere identico a quello del
  documento d'identità, con esempi come «Caseificio di Rossi G.»
  ([RC Ticino](https://www4.ti.ch/di/dg/rf/sportello/formulari-rc/di-iscrizione)).
- Se la ditta **non** è iscritta nel RC, nel registro IDI il nome è sempre
  nome e cognome del titolare. Un nome di fantasia compare solo come «Nome
  supplementare»
  ([Portale PMI](https://www.kmu.admin.ch/it/forma-giuridica-ditta-individuale)).
- Se la ditta è iscritta nel RC, le fatture devono riportare la ditta iscritta
  in modo completo e senza modifiche; puoi aggiungere un logo o un nome
  commerciale
  ([art. 954a CO](https://www.fedlex.admin.ch/eli/cc/27/317_321_377/it#art_954_a)).

**Cosa vuol dire per te.** «Timone» (o un altro nome della lista) può essere
solo il **marchio del prodotto** o il **nome supplementare** della tua ditta.
La ditta resta «[Nome Cognome]». Se un giorno la iscrivi nel RC, il nome di
fantasia può entrare nella ditta solo insieme al cognome, sul modello di
«Caseificio di Rossi G.»: la forma esatta va confermata con l'Ufficio RC
(di-rc@ti.ch).

Per lo stesso motivo l'impressum della landing mostra il tuo nome e cognome,
l'indirizzo completo e un contatto, non solo il marchio. Stripe lo chiede per
attivare TWINT: per le ditte individuali, nome e cognome completi del titolare
([Stripe Docs](https://docs.stripe.com/payments/twint)).

È anche il tema del post del 26.10 in `contenuti-social.md` («Il nome della
ditta individuale vuole il tuo cognome»): vale prima di tutto per te.

## 7. Come rinominare nel codice e nei documenti

Esempio con «Timone». Esegui i comandi dalla cartella del progetto.

### Codice

1. **`src/lib/sito.ts`**: cambia `nome: "Bussola"` con il nuovo nome. Nello
   stesso file c'è anche l'etichetta di navigazione «Chiedi a Bussola», scritta
   a mano.
2. `sito.nome` viene già usato da layout, home, impressum, privacy, immagine di
   anteprima (`src/app/opengraph-image.tsx`), mittente delle e-mail della lista
   d'attesa (`src/app/lista-attesa/azioni.ts`) e `src/data/passi.ts`: queste
   parti cambiano da sole.
3. **Testi scritti a mano.** Il nome compare ancora in una trentina di file:
   la landing (`src/components/landing/`), la chat (`src/app/chat/`,
   `src/lib/chat/`, compreso il prompt `src/lib/chat/prompt.ts`, dove l'IA dice
   «Sei Bussola»), il percorso (`src/app/percorso/`,
   `src/components/percorso/`, `src/lib/percorso/`, compreso il nome del
   calendario `.ics`), `src/data/passi.ts`, la pagina di conferma della lista
   d'attesa, lo script `scripts/importa-fonti.ts` e alcuni test. Per vederli
   tutti:

   ```sh
   grep -rn "Bussola" src scripts
   ```

4. Sostituzione in blocco (rinomina anche `IconaBussola` e `chiediABussola`
   in modo coerente in tutti i file):

   ```sh
   # macOS
   grep -rl "Bussola" src scripts | xargs sed -i '' 's/Bussola/Timone/g'
   # Linux
   grep -rl "Bussola" src scripts | xargs sed -i 's/Bussola/Timone/g'
   ```

5. **Rileggi le frasi.** Controlla grammatica e genere: «Chiedi a …», «… è
   gratuito», «… è pensato per la Svizzera italiana». Con un verbo come
   Salpiamo alcune frasi vanno riscritte a mano.
6. **Non toccare** la migrazione già applicata
   `supabase/migrations/20261015000000_schema_iniziale.sql` (il nome è solo in
   un commento). `"name": "bussola"` in `package.json` è interno: puoi
   lasciarlo.
7. **Variabili d'ambiente** sul servizio di hosting: `NEXT_PUBLIC_SITO_URL`
   con il nuovo dominio, `EMAIL_MITTENTE` con un indirizzo del nuovo dominio,
   `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` se usi Plausible, e i dati del titolare per
   l'impressum (`NEXT_PUBLIC_TITOLARE_NOME`, `NEXT_PUBLIC_TITOLARE_INDIRIZZO`,
   `NEXT_PUBLIC_TITOLARE_EMAIL`).
8. **Controlla** che tutto funzioni:

   ```sh
   npm test && npm run typecheck && npm run lint && npm run build
   ```
